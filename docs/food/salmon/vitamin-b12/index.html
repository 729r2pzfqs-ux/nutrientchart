About vitamin B12

Vitamin B12 is needed for red blood cells, nerve function and DNA synthesis. The Daily Value is 2.4 µg. It occurs naturally only in animal foods (shellfish, fish, meat, eggs, dairy); vegans need fortified foods or supplements.

Frequently asked questions

How much vitamin B12 is in salmon?

Salmon has 2.38 µg of vitamin B12 per 3 oz (85 g), which is 99% of the Daily Value. Per 100 g it contains 2.8 µg.

Is salmon high in vitamin B12?

Yes. At 99% of the Daily Value per serving, salmon counts as an excellent source under FDA labeling rules (10% is 'good', 20% is 'high').

How much vitamin B12 do I need a day?

The FDA Daily Value is 2.4 µg. One 3 oz of salmon covers 99% of it.
